# Сайт Life RPG

Лендинг приложения в стиле «Аркада». Обычный статический сайт: `index.html`, `style.css`, `main.js`, `assets/logo.svg`. Сборка не нужна.

Светлая и тёмная темы переключаются сами по настройкам браузера или телефона. Цвета обеих тем задаются переменными в начале `style.css`.

## Скачивание и счётчик

APK лежит не в этой папке, а в релизах GitHub: `github.com/vladikkr/life-rpg/releases`. Кнопки «Скачать APK» ведут на файл `LifeRPG.apk` последнего релиза. GitHub сам считает скачивания, а `main.js` показывает их сумму по всем релизам («Скачали N раз»), версию и размер файла.

Новая версия выкладывается одной командой из папки `life-rpg-app`:

```powershell
powershell -ExecutionPolicy Bypass -File tools
elease.ps1
```

Скрипт собирает подписанный APK, проверяет ключ, создаёт релиз с `LifeRPG.apk` и публикует этот сайт. Контрольная сумма и данные сборки сохраняются только у разработчика: `life-rpg-app/app/release/RELEASE_INFO.txt`.

## Безопасность

- Все скрипты, стили, шрифты, иконки и видео лежат на сайте; сторонних CDN нет.
- Политика безопасности (CSP) в `index.html` разрешает загрузку только с самого сайта, а запросы — только к `api.github.com` (счётчик).
- Иконки собираются скриптом `website-tools/build-icons.js` (только нужные из Lucide).

## Как посмотреть локально

```bash
python -m http.server 5178 --directory website
```

Затем открой http://localhost:5178

## Как выложить в интернет

Подойдёт любой бесплатный статический хостинг: GitHub Pages, Netlify (перетащить папку `website` на app.netlify.com/drop), Cloudflare Pages или Vercel.
